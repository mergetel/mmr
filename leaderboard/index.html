Why this exists

A bot makes up this leaderboard every morning. It opens a pull request with the day's drama in the title and merges it, so the repo ships something every day whether I do or not.

Those merges go through merge.tel, the thing I actually make. It turns merged pull requests into posts, so a fake leaderboard announces itself and I don't have to. That's most of the point of it.
